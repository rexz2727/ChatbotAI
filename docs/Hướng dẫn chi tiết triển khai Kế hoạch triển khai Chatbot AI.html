HƯỚNG DẪN CHI TIẾT TRIỂN KHAI CHATBOT AI (BẢN KỸ THUẬT)

Tài liệu này dành cho Kỹ sư / Cán bộ IT phụ trách cấu hình hệ thống OpenClaw + Gemini chạy hoàn toàn trên máy chủ Local (0 VND), hỗ trợ đầy đủ bộ kịch bản thủ tục hành chính mô hình 2 cấp (Từ tháng 7/2025).

BƯỚC 1: CHUẨN BỊ MÔI TRƯỜNG MÁY CHỦ (LOCAL HOSTING)

Do sử dụng máy tính cơ quan, chúng ta cần cài đặt các nền tảng để chạy được AI và Framework.

  1. Tải và cài đặt Node.js (Bản LTS): Đây là lõi để chạy OpenClaw.
  2. Tải và cài đặt Python 3.10+: Đảm bảo tick chọn "Add to PATH" lúc cài đặt. Cần thiết để khởi chạy lõi Vector DB (ChromaDB).
  3. Cài đặt PM2 (Công cụ giữ cho phần mềm không bị tắt khi tắt màn hình đen): 
    npm install pm2 -g

BƯỚC 2: MỞ ĐƯỜNG HẦM BẢO MẬT BẰNG CLOUDFLARE TUNNEL

Máy tính ở cơ quan không có IP tĩnh trên mạng Internet. Ta dùng Cloudflare để giải quyết.

  1. Tải file cloudflared.exe từ trang chủ Cloudflare.
  2. Chạy lệnh để cấp một đường link HTTPS miễn phí nối thẳng vào cổng 3000 của máy tính (Nơi OpenClaw đang chạy): 
    cloudflared tunnel --url http://localhost:3000
  3. Lưu lại đoạn URL được sinh ra (Ví dụ: https://congan-abc.trycloudflare.com). Không tắt cửa sổ này.

BƯỚC 3: CẤU HÌNH KẾT NỐI MẠNG XÃ HỘI (WEBHOOK)

Bạn truy cập vào trang quản trị lập trình viên của Facebook (Meta for Developers) và Zalo (Zalo for Developers).

  • Lấy Page Access Token (Facebook) và Access Token (Zalo OA).
  • Tại phần thiết lập Webhook của hai nền tảng, dán đường link Cloudflare vừa có được. (Ví dụ Facebook: https://congan-abc.trycloudflare.com/webhook/facebook).
  • Lưu lại toàn bộ Token vào một file .env trong thư mục mã nguồn OpenClaw.

BƯỚC 4: THIẾT LẬP CƠ SỞ DỮ LIỆU LUẬT (RAG PIPELINE)

BƯỚC QUAN TRỌNG NHẤT BẢO ĐẢM TÍNH PHÁP LÝ: Với mô hình 2 cấp sau 2025, ta phải tách bạch cơ sở dữ liệu để chống lỗi "Râu ông nọ cắm cằm bà kia". Không nạp chung luật giao thông với luật cư trú.

Trong thư mục chứa ChromaDB, bạn tạo ra 6 tập dữ liệu (Collections) độc lập tương ứng với 6 lĩnh vực:

// Đoạn mã khởi tạo 6 kho dữ liệu Vector độc lập
const chroma = require('chromadb');
const client = new chroma.ChromaClient();

async function initDatabases() {
    await client.createCollection({ name: "db_cu_tru" }); // Luật cư trú
    await client.createCollection({ name: "db_can_cuoc" }); // CCCD, Định danh
    await client.createCollection({ name: "db_giao_thong" }); // Đăng ký xe, GPLX, Vi phạm
    await client.createCollection({ name: "db_an_ninh" }); // PCCC, Cơ sở ANTT
    await client.createCollection({ name: "db_ngoai_kieu" }); // Khai báo người nước ngoài
    await client.createCollection({ name: "db_khieu_nai" }); // Khiếu nại, tố giác
}

Sau đó, sử dụng mã nguồn chuẩn hóa (Parse) để nạp các tệp `.txt` chứa văn bản pháp luật tương ứng vào từng kho.

BƯỚC 5: LẬP TRÌNH KỊCH BẢN ĐỊNH TUYẾN (MULTI-AGENT ROUTING)

Trong file điều hướng của OpenClaw, chúng ta sẽ bắt sự kiện người dân bấm nút trên Menu và điều phối họ đến "Cán bộ ảo" (Agent) phù hợp.

// HÀM TIẾP NHẬN VÀ PHÂN LUỒNG TIN NHẮN
async function handleUserMessage(userId, message, buttonPayload) {
    // 1. CHUYỂN LUỒNG NẾU NGƯỜI DÙNG BẤM NÚT MENU
    if (buttonPayload === "MENU_GIAO_THONG") {
        db.setSession(userId, "AGENT_GIAO_THONG");
        return "Bạn đang ở Cổng thông tin Giao thông (Đăng ký xe, GPLX, Nộp phạt). Mời đặt câu hỏi.";
    } 
    if (buttonPayload === "MENU_CU_TRU") {
        db.setSession(userId, "AGENT_CU_TRU");
        return "Bạn đang ở Cổng thông tin Cư trú. Mời đặt câu hỏi về thường trú, tạm trú.";
    }
    // ... Tương tự cho 4 nút còn lại

    // 2. LẤY TRẠNG THÁI HIỆN TẠI VÀ CHUẨN BỊ GỌI AI
    let userState = db.getSession(userId);
    let taiLieuThamKhao = "";

    // 3. ĐỊNH TUYẾN VÀO CÁC KHO LUẬT CHUYÊN BIỆT
    if (userState === "AGENT_GIAO_THONG") {
        taiLieuThamKhao = await queryChromaDB("db_giao_thong", message);
    } 
    else if (userState === "AGENT_CU_TRU") {
        taiLieuThamKhao = await queryChromaDB("db_cu_tru", message);
    }
    else {
        return sendMainMenu(); // Ép người dùng chọn lĩnh vực
    }

    // 4. ÉP KHUÔN VĂN PHONG VÀ GỌI GEMINI 1.5 FLASH
    const systemPrompt = `
        Bạn là cán bộ Trực ban Công an Phường.
        1. Xưng hô: "Công an Phường" và "anh/chị/cô/bác".
        2. CHỈ TRẢ LỜI ĐÚNG VỚI TÀI LIỆU SAU: [${taiLieuThamKhao}].
        3. Tuyệt đối không tự suy diễn luật. Nếu tài liệu không có câu trả lời, hãy nói: "Xin lỗi, hiện tại tôi chưa có dữ liệu cho câu hỏi này. Đề nghị anh/chị ra trực tiếp Trụ sở trong giờ hành chính để được hướng dẫn."
        Câu hỏi của người dân: ${message}
    `;

    return callGeminiAPIWithBackoff(systemPrompt);
}

BƯỚC 6: XỬ LÝ CHỐNG SẬP (CONCURRENCY & EXPONENTIAL BACKOFF)

Để đảm bảo 10 người hỏi cùng lúc không làm sập gói Gemini API Free (giới hạn 15 req/phút), bắt buộc phải lập trình hàm gọi API theo cơ chế thử lại (Backoff):

// THUẬT TOÁN BẢO VỆ API KHỎI QUÁ TẢI (RATE LIMIT)
async function callGeminiAPIWithBackoff(prompt, retries = 3) {
    for (let i = 0; i < retries; i++) {
        try {
            // Gọi API Gemini 1.5 Flash
            const response = await geminiAPI.generate(prompt);
            return response.text;
        } catch (error) {
            // Nếu lỗi 429 là lỗi Quá tải do bị bấm cùng lúc
            if (error.status === 429) {
                console.warn(`Hệ thống đang nghẽn. Chờ ${2 * (i + 1)} giây để thử lại...`);
                // Người thứ 10 sẽ phải chờ 2s, nếu vẫn lỗi chờ tiếp 4s, 6s... ngầm bên dưới
                await sleep(2000 * (i + 1)); 
                continue;
            }
            throw error; // Các lỗi khác thì báo lỗi bình thường
        }
    }
    return "Hệ thống tra cứu hiện đang có quá nhiều người truy cập. Xin vui lòng nhắn lại sau 1-2 phút.";
}
