⚙️ Giai đoạn 1 & 2: Thiết lập Máy ảo & Môi trường

Đã hoàn thành

Cán bộ kỹ thuật đã thiết lập xong máy chủ ảo Hyper-V Debian Minimal (No GUI), cài đặt các gói thư viện nền tảng gồm Node.js, Python 3, PM2 và cấu hình kết nối.

Debian 12 Netinst Node.js LTS PM2 Python 3.11

🛠️ Giai đoạn 3: Triển khai Mã nguồn & Vector DB

Đang thực hiện

  • Tạo cấu trúc dự án Node.js chuẩn, cài đặt các npm packages thiết yếu và viết file cấu hình bảo mật .env.

    package.json .env.example

  • Xây dựng tệp db.js kết nối SQLite để lưu trữ trạng thái người dùng (họ đang hỏi về lĩnh vực nào để định tuyến chính xác).

    db.js

  • Tạo thư mục data/ chứa 6 tệp văn bản luật thô đại diện cho 6 lĩnh vực thủ tục hành chính mới phân cấp.

    data/cu_tru.txt data/can_cuoc.txt data/giao_thong.txt data/an_ninh.txt data/ngoai_kieu.txt data/khieu_nai.txt

  • Lập trình file init_db.js để tự động đọc 6 file văn bản luật, chia đoạn (chunking), tạo Vector Embeddings và nạp vào 6 collection độc lập.

    init_db.js

  • Phát triển file chatbot.js thực hiện logic nhận tin nhắn, chuyển luồng session khi ấn menu, truy vấn ChromaDB tương ứng và gọi Gemini API.

    chatbot.js

Chưa bắt đầu

    index.js
